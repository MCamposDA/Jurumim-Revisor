# Jurumim Revisor

This extension contains Jurumim Revisor (`Jurumim_Revisor.py`, in this extension's folder)
and the skill `jurumim-review` (`skills/jurumim-review/SKILL.md`). Use the skill whenever
the researcher talks about a literature search, PubMed / Web of Science / Scopus records,
a PRISMA table, screening, or a folder written by `Jurumim_Revisor.py --context`.

In short: you suggest, the researcher decides; cite record IDs as `[record_id]`; take
numbers from the files; never ask for or handle API keys (the researcher saves them with
`--set-keys` in their own terminal).
